# 水文地质 — 数据准备清单

这是 GEOLOGIA 原创工作指南，不是地下水模型，也不是针对具体场地的结论。

## 建议整理的数据
- 研究区边界和明确的坐标参考系统（CRS）。
- 井位、测量高程和垂直基准、井深、岩性、滤管区间、井结构和施工日期。
- 水位观测的日期时间、时区、测量方法、单位、参考点以及抽水/恢复状态。
- 抽水试验流量、持续时间、降深/恢复曲线和观测井距离。
- 补给估算的方法、时间范围、空间尺度和不确定性；地质、DEM 和地表水边界。

## 预检查
1. 区分测点以下水深与基准面上的水位高程。
2. 检查 CRS、单位、井号、日期、高程和重复记录。
3. 保留原始观测；修正和派生值应单独保存并记录来源。
4. 区分实测、估算、插值和假设值。
5. 确认不同数据的季节、时间段和空间范围一致。

## 建模边界
概念模型应说明含水层、隔水层、边界、抽水等应力和校准观测。仅有井记录或水位不能证明可持续出水量或钻井成功。
