# 矿产勘查 — 证据与 QA/QC

GEOLOGIA 原创勘查准备清单。矿化点、勘查靶区和矿产资源/储量不是同一类别。

## 收集证据
- 地质填图、岩性、蚀变、构造和区域背景。
- 地球化学样品 ID、坐标/CRS、样品介质和采样方法、现场重复样、制样、实验室、分析方法、检出限、单位和分析证书。
- QA/QC：空白样、认证标准物质、重复样、污染检查、批次接受标准和样品链记录。
- 地球物理方法、仪器、测线/网格间距、方向、高程、处理和反演假设。
- 若有钻探，记录孔口、测斜、岩芯采取率、区间、编录标准和数据库验证。

## 预检查
1. 核对样品身份和坐标；不要用含糊名称连接表格。
2. 统一单位和检出限表达，保留低于检出限的标记。
3. 在绘制或排序异常前处理 QA/QC 失败。
4. 区分实测分析、插值表面和勘查假设。
5. 记录历史矿点数据库的年代和完整性。

## 安全边界
异常只是需要进一步验证的假设，不是经济矿床证明。资源/储量报告需要专业标准、钻探、采样、估算和独立合格人员审核。
