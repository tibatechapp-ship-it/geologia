# 地震学 — 事件目录与波形质量

GEOLOGIA 原创工作指南。事件目录参数、波形测量和地震危险性解释属于不同证据类型。

## 元数据
- 事件 ID、UTC 发震时间、坐标、深度、震级数值和类型、不确定性及审核状态。
- 网络/台站/通道代码、台站坐标与高程、仪器响应、采样率、单位、时间质量和数据缺口。
- 处理历史、滤波、仪器响应去除、分析窗口和软件版本。
- 空间覆盖、台站几何和事件关联来源。

## 预检查
1. 不把不同震级类型当作同一量进行直接比较。
2. 振幅或频谱分析前确认波形单位和仪器响应。
3. 检查 UTC、采样率、缺失段、削波和台站元数据。
4. 保留原始波形和目录；处理参数应可复现。
5. 未确认审核状态的自动定位和震级应视为初步结果。

## 安全边界
事件目录或波形集合本身不能形成场地地震危险性评估。需要经过验证的震源模型、地震动模型、场地条件、复发假设和专家审核。
