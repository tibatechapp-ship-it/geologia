# 三维地质建模 — 证据与不确定性

GEOLOGIA 原创结构地质数据准备指南。三维模型是受观测约束的解释，不是地下结构的直接测量。

## 输入数据
- 地质图、比例尺、图例、测绘日期和来源。
- 地层单元、接触界线以及界线类型（观测或假设）。
- 构造测量：位置、方位、倾角、测量方法和质量。
- 断层迹线、观测到的位移和不确定性。
- 钻孔约束、岩性日志、地球物理剖面、DEM、CRS 和垂直基准。

## 建模准备
1. 区分观测要素与解释/数字化要素。
2. 检查方位约定、单位、重复测量和坐标一致性。
3. 明确地层顺序、不整合和不确定关系。
4. 将模型范围限制在观测支持范围内，并标记外推区域。
5. 数据不能唯一约束几何时保留备选解释。

## 审核边界
报告输入覆盖、假设、模型版本和不确定性。视觉上平滑或合理的模型不能证明地质结构、储量或钻探目标。
